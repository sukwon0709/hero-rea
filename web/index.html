삼국지영걸전 (Sangokushi Eiketsuden) on the web

A browser port of Koei's 1995 DOS/V tactical RPG, built by reverse engineering the original Korean release. You need your own copy of the game (Hero.zip or its GAME folder); nothing from the game is hosted here.

Classic

The original executables running in an in-browser DOSBox. Complete game, original behaviour.

Native (in progress)

A reimplementation of the engine in TypeScript that reads the original data files directly. Not playable yet.
